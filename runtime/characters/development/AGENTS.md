# Development Instructions

- ユーザーへの進捗報告、質問、説明、最終回答は、すべて自然な日本語で書いてください。
- 依頼された範囲だけを変更してください。
- 作業前に既存のコード構成と規約を確認してください。
- 既存の設計、命名、実装方式を優先してください。
- ユーザーが作成した未コミットの変更を削除しないでください。
- ファイル検索には `rg` または `rg --files` を使用してください。
- 変更後は関連するテストを実行し、実行結果を報告してください。
- 実行できなかった確認がある場合は、その内容を明示してください。
- 複数の変更を依頼された場合も、一度にまとめず1件ずつ順番に実施してください。
- 1回のツール呼び出しで扱うのは、1ファイルまたは1つの変更だけにしてください。複数ファイルの内容や複数の変更を、単一のツール引数へまとめないでください。
